# SEO Setup for GTA6 Vault

## Google Search Console (Required for ranking tracking)

### Step 1: Verify Domain Ownership
1. Go to https://search.google.com/search-console
2. Add property: `https://gta6-vault.com`
3. Choose "URL prefix" method
4. Verify using one of these:
   - **HTML file upload** (easiest): Download verification file → upload to `/public/` → commit & push
   - **DNS record** (requires domain host access)
   - **Meta tag** (easiest for Next.js): Add to `<head>`
   - **Google Analytics** (if you setup GA4)

### Step 2: Preferred domain
Set https://www.gta6-vault.com as canonical (or without www, depends on your setup)

### Step 3: Sitemaps
Submit:
- `https://gta6-vault.com/sitemap.xml` (auto-generated by Next.js)
- `https://gta6-vault.com/robots.txt`

---

## Google Analytics 4 (Optional but recommended)

### Setup:
1. Create GA4 property: https://analytics.google.com
2. Add tracking ID to `app/layout.js`:
   ```javascript
   import { GoogleAnalytics } from '@next/third-parties/google'
   
   export default function RootLayout() {
     return (
       <html>
         <body>
           <GoogleAnalytics gaId="G-XXXXXXXXXX" />
         </body>
       </html>
     )
   }
   ```

## Core Web Vitals Check

### Run Lighthouse:
```bash
npm install -g lighthouse
lighthouse https://gta6-vault.com --view
```

### Metrics to track:
- **Largest Contentful Paint (LCP)** - target: < 2.5s
- **First Input Delay (FID)** - target: < 100ms  
- **Cumulative Layout Shift (CLS)** - target: < 0.1
